# TC 35PM ST 2067-104 IMF - OPL - Composite and Blend Macros

This is a project to track issues on ST 2067-104 for engineering document development work.
Publication includes:
- SMPTE Standard document
- Schema XSD

Please submit an [issue](https://github.com/SMPTE/st2067-104/issues) if you have a comment or suggestion.

Project details:
1. Title - 35PM-ST-2067-10x-OPL-Composite and Blend Macros
2. Description - 
This project develops the processing macros for image composite and blending between a foreground and a background plate with an alpha (channel) image to control the operation. The macros are part of the IMF OPL framework defined by ST 2067-100.
3. Problem to be Solved -
Rasterized subtitles, forced narrative and caption burned in by image compositing and blending for theatrical and TV episodic releases is essential to the processing of IMF compositions. Sign language overlay on main image sequence is also common for the broadcast industry. Workflow automation using the IMF OPL framework requires the standardization of the compositing and blending operations as OPL macros.
4. Project Scope -
Develop a standard for the IMF OPL image composite and blend macros as a part of the IMF OPL document suite.
